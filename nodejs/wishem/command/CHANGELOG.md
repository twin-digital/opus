### Minor Changes

- 909ae54: Add the package `@thrashplay/wishem-command` with the `wishem` command, which starts a construct for a model folder.
- 909ae54: Add the option `--product-code`, which names the product code that each product construct loads.
- 909ae54: Run the construct list and the construct manager with the option `--product`, so that each product construct runs in a child process.
