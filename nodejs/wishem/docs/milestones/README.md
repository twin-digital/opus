# Test guides of the milestones

A test guide is the test plan of one milestone. It lists the new features of the milestone. A person follows it by hand, alone, to see and test what the milestone delivered. The rules for a guide are in `nodejs/wishem/docs/autonomous-flow.md`, in the section "The test guide of a milestone".

| A3 React views | [a3-react-views.md](a3-react-views.md) | `a3-react-views/` |
