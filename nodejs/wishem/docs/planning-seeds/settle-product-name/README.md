# Product name

> Planning seed, not a specification. It collects what the blueprint knows about this topic, as the start of its brainstorm. See `../../README.md` for the status labels.

## Goal

This topic is the decision on the final name of the product. Wishem is the working name.

## What is agreed

- The owner selected "Wishem" as the working name. [`vision.md`](../../vision.md#the-name) and [`brand.md`](../../brand.md) tell the story of the name.
- Wishem is also the name of the agent. The short names are 'shem and 'shemmy.
- A check on 2026-11-22 found no product, npm package, or GitHub account with the name. Wishew, an iOS app, is one letter away. [`brainstorm.md`](../../brainstorm.md) has the results for each name that was checked.

## Open questions

1. **Is Wishem the final name?**
2. **Is the name free as a trademark?** Trademarks were not checked.
3. **Which domain names are necessary?** `wishem.com` is held by a different party.
