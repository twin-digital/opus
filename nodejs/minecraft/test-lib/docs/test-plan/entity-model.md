# Test plan — entity-model

Covers `src/entity.ts` and `src/query.ts`: `createEntity`/`createPlayer`, id assignment, per-entity
fields, the tag set, `dimension.spawnEntity`, `triggerEvent` recording, `remove()`, `invalidate()`
and the invalidation guard as an entity shows it, and the `EntityQueryOptions` matcher behind the
lookups and `entity.matches`.

Two files: `src/entity.test.ts` (E-rows) and `src/query.test.ts` (Q-rows). Every row is one `it`
under the `describe` heading it sits below. Cases marked **[ruling]** rest on a reading the spec
does not state outright — they are listed in the report as decisions to confirm before wave 2.

Shorthand used below: `server = createServer()`, `withVanillaDimensions(server)`,
`overworld = server.world.getDimension('overworld')`.
