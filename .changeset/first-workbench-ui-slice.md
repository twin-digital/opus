Draw the workbench model in a web browser. `@thrashplay/wishem-workbench-app` gets the first HTML renderer (`defineView`, the `AppBar` view, and a client of the core), a page that follows each change to the model, and a `start` script that runs the core and the page in one command. `@thrashplay/wishem-core` exports `CoreReader`, the read operations of a core.
