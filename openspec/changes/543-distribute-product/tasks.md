# Tasks

Rules for each task:

- Each automated test with real processes or a browser keeps a margin: each time limit is at least 3 times the expected time, each wait has its own limit that is less than the test timeout, and the test leaves no process and no container behind, on a pass or on a failure (it kills each process group and removes each container of its own run). Use port 0, or a port that the test reads from the line of the process.
- Run lint, the type check, the tests, and builds only for the packages of the task, in a slot: `node nodejs/wishem/docs/flow-scripts/heavy.mjs <command>`.
- `design.md` gives the decisions (D1 to D11), the interfaces, and the test guide. The specs in `specs/` give the behavior.
