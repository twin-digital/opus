# Tasks

Rules for each task:

- Run each heavy command (lint, type check, test, build, a Docker run) for this package only, under the lock: `flock -w 15 /tmp/wishem-heavy.lock timeout 140 <command>`. If `flock` gives exit code 1, run the same command again, at most 40 times. On exit code 124, stop and report it with the output of `lslocks`. Exception: when `godot:image` ends with exit code 124, run it again at most 3 times (BuildKit keeps each finished layer).
- Write each test before its code, and see it fail first. The report shows the failing run.
- Run Godot only in the Docker image of Task 1. Do not install a tool on the computer.
- Write no file outside the worktree. Put scratch files in `.superpowers/`.
- Do no background work: no command in the background, no monitor, and no wait for a later event. When a check needs two processes at the same time, write a scratch Node.js program in `.superpowers/` that starts both as child processes, does the check, stops both, and prints the result. Run it as one foreground command under the lock.
- Report each thing that is not in the scope of the task, and do not correct it. Report each gap of `nodejs/wishem/hub/LINK.md` that you find, and do not change `LINK.md` before Task 7.
